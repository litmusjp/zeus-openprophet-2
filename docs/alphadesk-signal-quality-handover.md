## Architecture and delivered source

- AlphaDesk's existing API serves authenticated strategy assessments. The opt-in `SIGNAL_QUALITY` scope uses its own fresh connected-opportunity evidence and returns `PASS`, `FAIL`, or `UNAVAILABLE`, plus a score only when supported. The older account-verified scope remains separate and is still the default. AlphaDesk's own GUI, worker, and Alpaca account are not OpenProphet broker accounts.
- OpenProphet L1 and L2 have distinct, broker-verified Alpaca paper accounts. Both use the same backend-held AlphaDesk API key as one client; the account and sandbox identifiers sent to AlphaDesk are declared identity, **not** independent broker verification. OpenProphet retains its account-verified opening authorization, broker identity and risk checks, and final order boundary. A signal-quality `PASS` alone does not authorize an order.
